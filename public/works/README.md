# 実績カードのスクリーンショット置き場

このフォルダに画像を置くと、講師紹介セクションの実績カードに自動で表示されます。
置いていないカードは、いままでどおり文字だけのカードのままです(リンク切れにはなりません)。

## ファイル名

`lib/works.ts` の `slug` と同じ名前にしてください。拡張子は png / jpg / jpeg / webp のいずれか。

| アプリ | ファイル名 |
| --- | --- |
| Tedori | `tedori.png` |
| サロン予約台帳 | `salon-ledger.png` |
| anime-trips | `anime-trips.png` |
| 適職みつかる.com | `tekishoku.png` |
| 今の会社、続けるといくら損？ | `life-plan.png` |
| MoguMogu | `mogumogu.png` |

## 推奨サイズ

**1200 × 750px(横長・16:10)**。カード上部に横幅いっぱいで表示され、上端を基準に切り取られます。

撮り方は、PCのブラウザでそのサイトを開いて、ウィンドウ幅を 1200px 前後にしてから
スクリーンショットを撮るのが一番きれいです。ページの一番上(ファーストビュー)を撮ってください。

縦長のスマホ画面のスクリーンショットでも表示はできますが、上端しか見えないので
横長のほうがおすすめです。

## 注意

- 実在の個人情報・顧客情報が写り込んでいないか、置く前に必ず確認してください。
- 1枚あたり 400KB 以下を目安に。大きすぎると表示が重くなります。
