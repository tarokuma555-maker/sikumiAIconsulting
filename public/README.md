# public/

静的ファイルを置く場所です。`/ファイル名` でアクセスできます。

## 講師写真

`teacher.png`(または `.jpg` / `.jpeg` / `.webp`)を置くと、
LPの講師紹介セクションに自動で表示されます。
ファイルがない間はプレースホルダー(枠だけ)が表示されるので、
置き忘れても画像リンク切れにはなりません。

- 表示サイズ: 240×240(正方形にトリミングされます)
- 推奨: 480×480 以上の正方形。人物が中央に写っているもの

## 実績のスクリーンショット

`works/` フォルダに置きます。詳しくは `works/README.md` を見てください。

## 操作の実演動画

`demo.mp4`(または `demo.webm`)を置くと、「実際の操作イメージ」セクションの
作図パネルが動画に差し替わります。置いていない間は作図パネルのままなので、
動画がなくてもセクションとして成立します。

- 内容: 日本語で指示 → AIが動く → 成果物ができる、までの画面録画
- 推奨: 横長(16:9)・30〜60秒・**20MB以下**。音声はなくても構いません
- `demo.jpg`(または `.png` / `.webp`)を一緒に置くと、再生前のサムネイルになります
- 実在の顧客名・社名・個人情報が映り込んでいないか、置く前に必ず確認してください
