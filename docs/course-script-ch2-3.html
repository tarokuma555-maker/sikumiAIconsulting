第2章 自分の「面倒な作業」を見つける

全4本・約40分 ／ 到達点:任せる候補の作業を3つ、書き出せている

この章のねらい

まだ道具は触りません。先に「何を楽にしたいか」を決めます。 ここを飛ばすと、第3章でClaude Codeが動いたあと「で、何をさせよう」で止まります。

この章には受講者が手を止めて書き出す回(2-4)があります。 そこを飛ばされると第4章が成立しないので、各本の最後で繰り返し促してください。

2-1 まず、1週間の作業を全部書き出す
約8分画面録画
話すこと

いきなり「何を自動化したいですか」と聞かれても、たぶん出てきません。私も出ませんでした。 面倒な作業ほど、慣れてしまって意識に上らないからです。

なので先に、1週間ぶんの作業を全部書き出します。 月曜の朝から金曜の夕方まで、順番に。ひな形集の「作業の棚卸しシート」を使ってください。

粒度のコツをひとつ。「メールを見る」は細かすぎます。「週次報告書を作る」くらいがちょうどいい。 目安は「30分以上かかるもの」です。それ未満は、いま無視して構いません。

いちばん正確なのは、1週間ほんとうに記録を取ることです。でもそれを待つと止まってしまうので、 まずは思い出せる範囲で書いてください。あとから足せます。

画面
  • 棚卸しシートを開いて、実際に埋めていくところを見せる
  • 書き込む例は架空の職場のもの(第1章1-5で言ったことを自分でも守る)
  • 「30分以上かかるもの」を画面の隅に出しておく
2-2 選ぶ基準は3つだけ
約9分画面録画この章の核
話すこと

書き出した中から選びます。基準は3つです。毎週やる。手順が決まっている。判断が少ない。

ひとつめ、毎週やること。年に1回の作業を楽にしても、割に合いません。 毎週やるものなら、1回30分の短縮でも年に25時間返ってきます。

ふたつめ、手順が決まっていること。ここが大事です。 人に説明できる作業は、AIにも説明できます。 逆に、自分でも説明できない作業は、AIにも頼めません。 「新しく入った人に、口で説明して任せられるか」で考えてみてください。

みっつめ、判断が少ないこと。第1章で言ったとおり、AIは平気で間違えます。 判断が多い作業だと、間違いに気づけません。

この3つに、○△×をつけるだけです。点数の計算は要りません。 ○が3つ揃ったものを選びます。揃わなければ、まだ早いということです。

画面
  • 2-1で埋めたシートに、3列(毎週 / 手順 / 判断)を足して○△×をつけていく
  • ○が3つ揃うもの、揃わないものを両方見せる
  • スライド:「年に25時間」の計算を1枚で(30分 × 週1 × 50週)
2-3 最初に選んではいけない作業
約7分画面録画
話すこと

逆に、最初には選ばないほうがいい作業を挙げます。

お客様に直接届くもの。送信メール、提案書、請求書。間違いがそのまま外に出ます。
毎回やり方が違うもの。手順が決まっていないので、頼みようがありません。
自分でも説明できないもの。「なんとなくこうしてる」は、まだ言葉になっていません。

ここで、よく言われることがあります。「でも、それが一番面倒なんです」と。 分かります。面倒な作業ほど、判断が多いものです。

その場合は分解してください。たとえば提案書づくりなら、 「何を提案するか決める」のはあなたの仕事のまま。 「決めたことを、いつもの形に流し込む」のは渡せます。 丸ごと渡そうとしないこと。判断の手前だけを切り出す。これがコツです。

画面
  • スライド:「最初に選ばない3つ」
  • スライド:提案書づくりを縦に分解した図——上が「自分の仕事」、下が「渡せる部分」
  • この図は第1章1-2の「下ごしらえ」の絵と同じ形にして、つながりを見せる
2-4 ワーク:3つに絞る
約16分ワーク飛ばされやすい
話すこと

ここは手を動かす回です。動画を止めて、実際にやってください。 ここで3つ選べていないと、このあとの章が「見るだけ」になってしまいます。

手順は3つです。1週間の作業を書き出す。3つの基準で○△×をつける。○が3つのものを選ぶ。 全部で15分ほどです。

3つ選べなかった場合。それでも構いません。1つでも大丈夫です。 逆に5つ以上ある場合は、3つに絞ってください。 最初から欲張ると、どれも完成しません。

選んだら、その紙かファイルを手元に置いたまま次の章に進んでください。第4章でそのまま使います。

画面
  • 手順3つをスライドで出し、そのまま静止画で15分置く(受講者が作業する時間)
  • あるいは冒頭2分で説明し、「止めてください」と明示して終わる短い本にする
  • どちらの形にするかは、撮ってみて決めてください。静止画15分は間延びする可能性があります

第3章 Claude Codeを使えるようにする

全8本・約90分 ／ 到達点:自分のパソコンでアプリが動き、日本語で1往復できる

この章の勝敗を分ける1点

環境が「ローカル」になっているか。これだけです。 ここを間違えると、以降のすべてが動きません。しかもエラーは出ません。 ただ「自分のファイルが見つからない」という、原因の分かりにくい形で失敗します。

3-1でなぜ大事かを、3-4で実際の操作を見せます。2回言ってちょうどいいくらいです。

3-1 「ローカル」と「クラウド」の違い
約9分画面録画最重要
話すこと

Claude Codeを使う前に、ひとつだけ知っておいてほしいことがあります。 Claudeには「どこで動くか」の設定があります。

ひとつはローカル。あなたのパソコンの中で動きます。 だから、あなたのフォルダの中のファイルを読んだり、書いたりできます。

もうひとつはクラウド。インターネットの向こうにある、別のマシンで動きます。 こちらは便利な使い方もあるのですが、あなたのパソコンの中には一切触れません。

この講座でやりたいのは、あなたのパソコンにある、毎週の面倒な作業を楽にすることです。 なので使うのはローカルだけです。ここを間違えると、何をやっても動きません。

それから、ブラウザでclaude.aiを開くやり方もありますが、 そちらはクラウドしか選べません。手軽なのでつい開きたくなりますが、 この講座では使いません。必ずアプリのほうを使ってください。

画面
  • スライド:ローカル=手元のパソコン / クラウド=向こうのマシン、の絵
  • 実際にブラウザ版を開いて見せる。「リポジトリを選択」しか出ないところまで
  • 見分け方:サイドバーに「Claude Desktop version available」と出ていたら、それはブラウザ版
  • アプリ側に切り替えて、左端が「ローカル」と出ている状態を見せる
3-2 入れる:Windows編
約14分画面録画Windows実機
話すこと

Windowsをお使いの方向けです。Macの方は次の動画へどうぞ。

入れるものは2つあります。Claudeのアプリと、Git for Windowsというものです。 2つめは聞き慣れないと思いますが、Claudeが内部で使うので必要というだけです。 中身を理解する必要はありません。入れるだけです。

順番も決まっています。Git for Windowsを先に入れて、そのあとアプリを起動してください。 逆にしてしまった場合は、アプリを一度閉じて開き直せば大丈夫です。

画面
  • Git for Windows のダウンロードから、インストーラを進めるところまで
  • Claudeアプリのダウンロード、サインイン、Codeタブを開くところまで
  • インストーラの選択肢は「そのまま次へ」で通す。選択肢の意味を説明しない
収録前に確認
  • Windows実機が必要です。お持ちでなければ、ここだけ外注か後日撮影にしてください
  • ARM版Windowsは別のインストーラです。台本では触れず、質問が来たら個別対応でよいと思います
3-3 入れる:macOS編
約10分画面録画
話すこと

Macの方向けです。こちらはClaudeのアプリを入れるだけで済みます。

ダウンロードして、アプリケーションフォルダに入れて、開く。サインインして、上の「Code」タブを押す。 ここまでで準備は終わりです。

画面
  • ダウンロード → アプリケーションへドラッグ → 起動 → サインイン → Codeタブ
  • Codeタブの位置を、はっきり指し示す。「ホーム」と並んでいることを言う
3-4 環境を「ローカル」にしてから、フォルダを選ぶ
約11分画面録画最重要
話すこと

ここが第3章でいちばん大事なところです。入力欄のすぐ上に、小さなボタンが並んでいます。 そのいちばん左を見てください。

ここが「ローカル」になっていれば正解です。なっていなければ、押して切り替えてください。

切り替わると、その右がフォルダを選ぶボタンになります。 ここで、作業したいファイルが入っているフォルダを選びます。

フォルダ選びにもコツがあります。いきなり「書類」フォルダ全体を選ばないでください。 範囲が広すぎると、関係ないファイルまで見えてしまいます。 まずは、練習用のフォルダを1つ作るところから始めましょう。

デスクトップに「AI練習」という名前でフォルダを作ってください。 そこにファイルを2、3個入れておきます。この講座では、しばらくこのフォルダだけを使います。

画面
  • 間違った状態(クラウド)と、正しい状態(ローカル)を並べて見せる
  • 実際に切り替える操作
  • デスクトップに「AI練習」フォルダを新規作成 → 中身を入れる → 選択する、まで通しで
収録前に必ず確認
  • 「AI練習」のような、ふつうのフォルダを選んだときの画面を先に確かめてください。 太郎さんがいま選んでいる claude-projects は開発用のフォルダなので、 ブランチ名や「ワークツリー」といった、受講者には無関係なボタンが出ています。 ふつうのフォルダでそれらが出るのか出ないのかで、説明の要否が変わります
  • 出る場合は「これは無視してください」と一言添える。出ないなら触れない
3-5 最初の1回:日本語でお願いしてみる
約12分画面録画感動する回
話すこと

では、初めてお願いしてみます。最初は、何も変えない頼み方からいきましょう。

入力欄に、こう打ってみてください。
「このフォルダに何が入っているか、日本語で教えて」

これだけです。コマンドも記号も要りません。……いま、あなたのパソコンの中のフォルダを、 Claudeが実際に見て答えました。これが「ローカル」ということです。

次に、何かを作らせてみます。
「このフォルダに、練習用のメモというファイルを作って。中身は今日の日付だけでいい」

フォルダを開いてみてください。ファイルができているはずです。 読むこともできるし、作ることもできる。ここまで来れば、あとは応用です。

なぜこの順番かというと、読むだけの頼みごとは、失敗しても何も壊れないからです。 いきなり「消して」「書き換えて」から始めないでください。

画面
  • 入力 → 返事、を等速で見せる(早送りしない。待つ体験も含めて見せる)
  • ファイルができたことを、Finder / エクスプローラーを開いて確認
  • 許可を求める画面が出たら、それも隠さず見せて、読み方を説明する
3-6 画面の見方と、変わったところの確かめ方
約10分画面録画
話すこと

画面の見方を整理します。覚えるのは3か所だけです。

入力欄。ここに日本語で書く。
その上の小さなボタン。左端が「ローカル」、その右が今のフォルダ。
真ん中の広い部分。やりとりと、Claudeがやったことが出ます。

大事なのは、ファイルが変わったときの見え方です。 Claudeがファイルを直すと、どこをどう変えたかが画面に出ます。 足した行と、消した行が色分けされて見えます。

ここは必ず目を通してください。第1章で言ったとおり、AIは間違えます。 変わったところを見るのは、あなたの仕事です。

画面
  • 3か所を順に指し示す(枠で囲むなどの後処理を入れる)
  • 実際にファイルを1行直させて、変更の表示が出るところを見せる
3-7 やってはいけないこと
約8分画面録画安全の回
話すこと

安全に使うために、4つだけ守ってください。

ひとつ。大事なフォルダを丸ごと選ばない。 「書類」フォルダ全体やデスクトップ全体ではなく、練習用のフォルダから始めます。

ふたつ。「いらないものを消して」と頼まない。 何がいらないかを決めるのは判断です。第2章でお話ししたとおり、判断は渡さない。 消す作業は、慣れてからでも遅くありません。

みっつ。大事なファイルは、先にコピーを取る。 本物を直させる前に、複製を1つ作っておく。これだけで、ほとんどの事故が防げます。

よっつ。許可を求める画面が出たら、読む。 Claudeは、何かをする前に「これをしていいですか」と聞いてくることがあります。 ここを「毎回自動で許可」に設定してしまうと、聞かれなくなります。 慣れるまでは聞かれる設定のまま使ってください。

画面
  • 許可を求める画面を実際に出して、どこを読むか説明する
  • 設定を変えるボタンの場所を見せて、「ここは触らないでください」と言う
収録前に確認
  • 許可の設定は画面左下にあります。太郎さんの環境はいま「自動」になっています。 収録するときは、初期状態(聞いてくる設定)に戻してから撮ってください。 「自動」のまま撮ると、許可画面が一度も出ず、この回が撮れません
  • 日本語の表示名を画面で確認して、台本の言い方をそれに合わせてください
3-8 つまずいたときに見るところ
約12分画面録画問い合わせを減らす回
話すこと

最後に、うまくいかないときの確認手順です。上から順に見てください。

1. 左端は「ローカル」になっていますか。ここが9割です。
2. フォルダは正しいものが選ばれていますか。別のフォルダを見ているかもしれません。
3. ファイルは、そのフォルダの中にありますか。選んだフォルダの外にあるものは見えません。
4. 頼み方に、3つ入っていますか。何を・どうしてほしいか・どんな形で。
5. それでもダメなら、新しく始め直す。長いやりとりは噛み合わなくなることがあります。

ここまでやってもダメなときは、ご質問ください。 購入時にご案内したメールアドレスに、この5つのどこまで試したかを書いて送っていただけると、 こちらもすぐ答えられます。30日間、動画の内容についてのご質問をお受けします。
