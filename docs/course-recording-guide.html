動画の作り方

収録は太郎さんにしかできません。それ以外は用意できます。 いちばん早く1本目を仕上げる道と、そのあとの見通しをまとめました。

作成 2026-08-20 版 v0.1
できることと、できないこと

動画づくりは 台本 → スライド → 素材 → 収録 → 書き出し の順で進みます。 このうち収録だけが太郎さんの手作業で、前後は私が用意できます。

工程だれがいまの状態
台本私第0〜3章 完成
スライド私第0章 完成(8枚・ナレーション入り)
画面に映す練習用ファイル私これから(第1章以降で必要)
ひな形集私これから
収録(声・顔・画面)太郎さんここだけ代われません
書き出し太郎さんKeynote / PowerPointの機能で完結

いちばん早い道:第0章を今日撮る

15分・3本 ／ アプリの画面もWindowsもひな形集も要りません

第0章は顔とスライドだけで成立します。アプリの画面を映さないので、 収録前の確認事項(ローカル設定・許可の設定・Windows実機)にも一切引っかかりません。 いま手元にあるもので、最後まで撮れる唯一の章です。

編集ソフトは要りません

KeynoteとPowerPointには、スライドを送りながら声を録り、そのまま動画に書き出す機能が入っています。 第0章はこれだけで完成します。別の編集ソフトを覚える必要はありません。

手順 1 スライドを開いて、ナレーションを確かめる
10分
やること
  • ch0-slides.pptx を Keynote か PowerPoint で開きます
  • 各スライドの「発表者ノート」に、話す内容がそのまま入っています。そこを読めば収録できます
  • Keynoteは 表示 →「発表者ノート」、PowerPointは下部の「ノート」で表示できます
  • 自分の言い回しに直したいところは、先に書き換えてください
補足
  • フォントは游ゴシックを指定しています。見た目が崩れていたら、好みのフォントに置き換えてください
  • 色はLPと同じ(紺 #24457F / 山吹 #E8A33D)にそろえてあります
手順 2 0-1 だけ、先に顔を撮る
20分顔出し
やること
  • Macに入っている QuickTime Player を開きます
  • ファイル →「新規ムービー収録」で、カメラの録画が始められます
  • 0-1(約5分)はスライドなし・顔だけです。台本の「話すこと」を読みます
撮るときのコツ
  • 窓を正面にして座る。逆光だと顔が暗くなります
  • カメラは目線の高さに。本を積んで上げるだけで印象が変わります
  • 音がいちばん大事です。映像が多少粗くても許されますが、音が悪いと最後まで見てもらえません。 エアコンを止め、できればイヤホンのマイクを使ってください
  • 背景に実在の書類が映り込んでいないか、撮る前に振り返って確認してください
  • 言い間違えたら止めずに、少し間を置いて言い直す。あとで切れます
手順 3 0-2 と 0-3 を、スライドを送りながら録る
40分スライド＋声
やること
  • Keynote: 再生メニュー →「スライドショーを記録」
  • PowerPoint: スライドショータブ →「記録」
  • (表示名はバージョンで少し違います。「記録」と付いた項目を探してください)
  • 録音を始めて、ノートを読みながらスライドを送ります
  • 1枚ごとに録り直せます。通しで完璧に録る必要はありません
分け方
  • 0-2 は スライド2〜4(できること / やらないこと / 比較表)
  • 0-3 は スライド5〜8(進め方 / 用意するもの / 質問サポート / 締め)
  • 2本に分けて書き出すか、1本で書き出してあとから切るかは、やりやすいほうで
手順 4 動画として書き出す
15分
やること
  • Keynote: ファイル → 書き出す → ムービー
  • PowerPoint: ファイル → エクスポート → ビデオの作成
  • 画質は 1080p を選びます。それ以上は容量が増えるだけです
  • ファイル名は 0-1_ようこそ.mp4 のように番号を頭に付けてください。並び順が崩れません
これで完成
  • この時点で、実際に売り物になる動画が3本できています

第1章から先に必要なもの

画面収録が入るので、準備が1段増えます

第1章以降は画面録画が中心です。Macなら QuickTime Player の ファイル →「新規画面収録」で撮れます。ソフトを買う必要はありません。

必要なものだれが用意内容
スライド(第1〜3章)私第0章と同じ形式で作れます
画面に映す練習用ファイル私架空の会議メモ、先月の報告書、練習用フォルダ一式。実在の情報を映さないために必須
ひな形集(7種)私1-6と第4章で実際に画面に映すもの
Windows実機太郎さん3-2のみ。無ければ後日撮影か外注
アプリの設定戻し太郎さん3-7を撮る前に、許可の設定を初期状態へ
かかる時間の目安

この形式(スライド＋画面録画、凝った編集なし)だと、 できあがり1分あたり、収録と手直しで5〜10分を見ておくと外しません。

  • 第0章(15分) → 1時間半〜2時間半。今日から着手できます
  • 第0〜3章(約3時間) → 15〜30時間。週末2〜3回ぶん

1本5〜12分に切ってあるのは、この撮り直しを軽くするためでもあります。 失敗しても、その1本を撮り直すだけで済みます。

次に私が作れるもの

1. 第1〜3章のスライド(第0章と同じ形式・ナレーション入り)
2. 画面に映す練習用ファイル一式(架空の会議メモ、先月の報告書、練習用フォルダ)
3. ひな形集7種

2番を先に作るのがおすすめです。これが無いと、第1章の実演で 実在の資料を映すことになり、1-5で自分が教える内容と矛盾します。
