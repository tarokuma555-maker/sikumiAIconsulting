講座プラン 要件定義

¥29,800の買い切り教材として何を作り、何を作らないかを決めるための文書です。 中身の制作に入る前に、ここで線を引いておきます。

返金の条件が「閲覧を開始したかどうか」で分かれています。 つまり、誰がいつ最初に動画を再生したかを記録できる仕組みが必須です。 これがないと、返金を求められたときに「まだ見ていない」と言われても反論できません。

動画をGoogleドライブやギガファイル便で渡す方式は、この一点だけで失格になります。 教材の置き場所を選ぶときの、最初の条件がこれです(第7節)。

02だれのための教材か

提案LPの内容から、受講者像をこう置きます。

  • 非エンジニアのビジネス職(企画・営業・事務・バックオフィス)
  • ふだんの仕事でExcelとブラウザは使える。プログラムを書いた経験はゼロ
  • ChatGPTは触ったことがあるが、「文章を直してもらう」程度で止まっている
  • まとまった学習時間は取れない。平日の夜か週末に、30分〜1時間ずつ
  • 「黒い画面」に強い抵抗がある。ここを解けるかが教材の成否を分けます

最後の1点が、この教材のいちばん難しいところでした。 ただしClaudeのデスクトップアプリを使えば、最初から黒い画面を見ずに始められます(第4節)。 LPで「黒い画面でプログラムを書くわけではありません」と書いている内容と、教材で見せる画面がようやく一致します。

03どこまでできるようにするか

ここがこの文書でいちばん重要な部分です。 講座プランのゴールを高く置きすぎると、伴走プラン(¥150,000)を買う理由がなくなります。 逆に低すぎると、¥29,800の価値がありません。

LPの講座プランには「お約束」の欄がありません。これは正しい状態です。 講座プランは成果を保証しないという前提で、以下のゴールを置きます。

講座プラン修了時点のゴール

提案受講者が、自分ひとりで次の4つができる状態。

  1. 自分の仕事の中から「AIに任せられそうな作業」を3つ挙げられる
  2. 自分のパソコンでClaude Codeを起動して、日本語で指示が出せる
  3. ひな形を使って、1つの作業の下書きをAIに作らせられる
  4. うまく動かないとき、自分で調べ直す手順を持っている

「実際の業務で運用に乗せる」「会社の事情に合わせて設計する」は伴走プランの領域として、 教材では扱いません。この線を教材の冒頭(第0章)で受講者にはっきり伝えます。 後出しにすると不満の原因になります。

04教材の中身(章立て案)

提案 全6章・合計およそ5時間30分。1本あたり5〜12分に切って、 細切れの時間でも進められるようにします。時間はすべて目安です。

第0章 この講座で、どこまでやるか 約15分

到達点:何ができるようになるか、何はやらないかを受講者が理解している

  • この講座のゴールと、あえて扱わないこと
  • 受講の進め方(順番に見る・手を動かす前提)
  • 必要なもの(パソコン・AIの利用契約)と、かかる費用の目安
第1章 仕事でAIを使うための基礎 約60分

到達点:AIに向く仕事と向かない仕事を、自分で判断できる

  • AIが得意なこと・苦手なこと(苦手を先に見せる)
  • 指示の書き方の型:何を・どうしてほしいか・どんな形で出すか
  • 思った通りにならないときの直し方
  • 会社の情報を渡さないための工夫(名前や数字を伏せる・架空データで作る)
  • 会社のルールが分からないときに確認すべきこと
第2章 自分の「面倒な作業」を見つける 約40分

到達点:任せる候補の作業を3つ、紙に書き出せている

  • 1週間の作業を書き出す(棚卸しシートを使う)
  • 選ぶ基準:毎週やる・手順が決まっている・判断が少ない
  • 最初の1つに選んではいけない作業(判断が多い・失敗の影響が大きい)
  • 受講者が実際に手を動かす回(ワーク)
第3章 Claude Codeを使えるようにする 約90分

到達点:Claudeアプリが動き、日本語で1往復のやりとりができる

  • Claude Codeとは何か。入口は2つある(アプリ / ターミナル)。この講座はアプリを使います
  • 入れ方:Windows編 — Claudeアプリに加えてGit for Windowsが必要(入れたあとアプリを再起動)
  • 入れ方:macOS編
  • Codeタブを開いて、作業するフォルダを選ぶ
  • 最初の1回:日本語でお願いしてみる
  • 画面の見方(どこに何が出るか、変更箇所の確かめ方)
  • やってはいけない操作(消してしまう系の指示)
  • つまずきやすい場所と、その直し方
第4章 ひな形を使って、1つ作ってみる 約90分

到達点:ひな形を自分の作業に当てはめて、下書きが出せる

  • ひな形の使い方(どこを自分の言葉に置き換えるか)
  • 例1:毎週の報告書の下書きを作る(LPの図と同じ題材)
  • 例2:ファイルの整理と名前の付け替え
  • 例3:いつも同じ内容のメールの下書き
  • 思った通りに出ないときの、確認する順番
第5章 続けられる形にする 約35分

到達点:来週も同じことを再現できる

  • 毎週使うための置き場所と、自分用の手順メモ
  • 人に見せる・引き継ぐときの注意
  • ここから先(伴走プランで何が変わるか)
付録 ターミナルを使うとき 約20分

到達点:必要になったとき、アプリの中のターミナルを開いて操作できる

  • ターミナルはClaudeアプリの中に入っています(Ctrl+`で下から出ます)。別のアプリを開く必要はありません
  • どんなときに必要になるか
  • 貼り付けるだけで済ませる進め方
なぜアプリを主にするか

Claude Codeにはデスクトップアプリとターミナルの2つの入口があります。 設定ファイル・CLAUDE.md・スキル・権限の設定は両方で共通なので、できることはほぼ同じです。

そのうえでアプリには、受講者にとって効きが大きい差があります。 スキル・プラグイン・外部サービス連携は画面から追加・管理でき、ターミナルを開かずに設定できます。 画像やPDFを貼って渡せるのもアプリだけです(ターミナルではできません)。 変更箇所を画面で見比べられるのも、非エンジニアには大きい違いです。

ターミナルが要る場面もありますが、ターミナルはアプリの中にあります。 別のアプリを立ち上げるのではなく、画面の下から出てくるだけです。 「黒い画面」への抵抗は、ここでほぼ解けます。だから付録に置きました。

章立てで意識したこと

第2章(作業を見つける)を、第3章(Claude Codeを入れる)より前に置いています。 道具の使い方から入ると「で、これを何に使うの?」で止まります。 先に「これを楽にしたい」を決めてから道具を触るほうが、最後まで進みます。

05ひな形集の中身

提案 LPで「よくある作業をAIに任せるためのひな形集」と約束しているものの中身です。 受講者がコピーして自分の言葉に書き換えるだけで使える状態にします。

ひな形使う場面形式
作業の棚卸しシート第2章のワーク。1週間の作業を書き出すスプレッドシート
指示文の基本形すべての土台。何を・どうしてほしいか・どんな形で文書
報告書・議事録まとめメモから下書きを作らせる文書
定型メールの返信いつも同じ内容の返信文書
ファイル整理・名前の付け替えフォルダの片づけ文書
表の集計・転記複数ファイルからの集計文書
情報を伏せるためのチェックリスト会社の情報を渡す前の確認チェックリスト

形式は、受講者が編集しやすいものに揃えます(第7節の決定事項)。 PDFで配るとコピーして書き換えるという使い方ができないので避けます。

0630日間の質問サポート

LPで「動画の内容についての質問(30日間)」と約束している部分です。 範囲を決めておかないと、実質的に無料の個別コンサルになります。

項目内容状態
期間30日間確定
起算日閲覧方法を案内したメールの送信日提案
対象教材の内容についての質問のみ。「動画のこの手順で動かない」はOK。「私の会社のこの業務をどう設計するか」は伴走プランの範囲提案
回数制限なし。ただし1往復を1件として扱う提案
返信の目安平日3営業日以内(伴走プランの「24時間以内」と差をつける)提案
窓口未定要決定
注意

返信の目安をLPに書いていないので、いま決めれば自由に設定できます。 ただし決めた内容は、教材の第0章か購入案内メールに明記してください。 書いていないと「すぐ返信が来るはず」と期待されます。

07教材の置き場所に必要な条件

どのサービスを使うかを決める前に、外せない条件を並べます。

  1. 誰がいつ最初に再生したか記録できる(第1節の返金条件のため。最優先)
  2. 買い切りで売れる(月額課金の仕組みしかないサービスは不可)
  3. 視聴期限を無期限にできる
  4. 入金から3営業日以内に案内できる(自動なら理想、手作業でも可)
  5. 受講者がスマホでも動画を見られる
  6. ひな形ファイルを一緒に配れる
  7. 個人事業主でも契約できる
  8. 値引きセールを勝手にかけられない(ブランドと価格が崩れるため)

候補としては、①教材販売サービスを借りる、②動画配信サービス＋決済を組み合わせる、 ③いまのLPに自分で作り足すの3通りがあります。 それぞれの料金と機能は変動するので、契約前に必ず現在の条件をご確認ください。 上の8条件を満たすかどうかで絞り込むのが早いです。

私の見立て

③(自分で作る)は、いまNext.jsのLPがVercelで動いているので技術的には可能ですし、 「自分の業務を仕組み化する」というサービス内容とも一致します。 ただし決済・返金の記録・動画の不正共有対策を自前で抱えることになります。

最初の数人に売る段階では①か②で早く出し、 売れ方が見えてから③に移すほうが、リスクが小さいと考えています。

08買ってから見るまでの流れ

提案特商法ページの記載と矛盾しない形にしています。

  1. 無料相談、またはLINEから購入の意思をもらう
  2. 支払方法(銀行振込 / クレジットカード)を決めて案内する
  3. 入金を確認する
  4. 3営業日以内に、閲覧方法を書いたメールを送る確定
  5. 受講者が最初に再生した日を記録する(返金判定のため)
  6. 案内メールの送信日から30日間、質問を受け付ける
  7. 30日経過時に、伴走プランの案内を1通送る

手順4のメールには、視聴期限がないこと・返金の条件・質問の期限と範囲を必ず書きます。 ここに書いておけば、あとで揉めません。

10決めていただきたいこと

次に進むために、判断が必要な6点です。それぞれ私の推奨も書いています。

決定1教材の置き場所

第7節の8条件を満たすものを選びます。ここが決まらないと、動画の書き出し設定も決まりません。

推奨: まずは教材販売サービスを借りて早く出す。自作は売れ方が見えてから。

決定2支払方法

特商法ページには「銀行振込、またはクレジットカード決済(Stripe)」と書いてあります。実際にどちらを用意しますか。

推奨: 両方。¥29,800は振込だと離脱が出ます。カードのほうが入金確認も早く、3営業日の約束を守りやすくなります。

決定3質問サポートの窓口

LINE公式アカウントを使うか、メールにするか。LINEは既にありますが、見込み客と受講者が同じ場所に混ざります。

推奨: メール。受講者だけを分けられ、やりとりが記録として残ります。

決定4動画に顔を出すか

「元・非エンジニア」が教えることがLPの売りなので、顔が見えるほうが一致します。撮影の手間と相談です。

推奨: 第0章と第5章だけ顔出し。他は画面録画＋音声。撮り直しがしやすくなります。

決定5すでにある素材

過去に作った資料・note記事・録画などはありますか。あれば第1章と第2章はかなり短縮できます。

確認したいこと: 流用できるものの有無。あれば章立てを組み替えます。

決定6いつ売り始めるか

締め切りが決まると、削るものが決まります。全6章そろわないと売れない、という制約はありません。

推奨: 第0〜3章(約3時間)で先行販売し、第4〜5章は追加公開する。買い切り・視聴期限なしなので、あとから足しても筋が通ります。

決定7特商法の動作環境を直すか

いまの特商法ページは「インターネットに接続されたパソコン(Windows または macOS)」だけです。 Windowsでアプリを使うにはGit for Windowsの導入が別途必要なので、 買ったあとに「動かない」と言われる余地があります。

推奨: 動作環境に追記する。「Windowsの場合はGit for Windows(無料)の導入が必要」と1行足すだけで、購入前に伝わります。

11作る順番の提案

決定1〜6が固まったあとの進め方です。

  1. 台本を全章ぶん先に書く。撮影より先に、全体の流れを文字で確定させます
  2. ひな形集を先に完成させる。第4章の台本はひな形が決まらないと書けません
  3. 第3章(Claude Codeのはじめかた)を最初に撮る。いちばん陳腐化が早く、作り直しが起きやすいため、手順を早く固めます
  4. 残りを撮る
  5. 受講者役を1人立てて、通しで試してもらう
  6. 購入から視聴までを、自分で1回通す(テスト購入)
  7. 販売開始
